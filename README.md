# Respiratory-Risk-Prediction

<h2>Description</h2>
Project utilizes multiple environmental data set in order to ascertain variables that have an impact on respiratory health across the United States broken up by region. Code is limited due to much of it being dependent on the machine that the original code was run on.
<br />

<h2>Languages and Utilities Used</h2>

- <b>Python
- Matplot
- numpy
- pandas
- sklearn
- seaborn
- addfips
- us
- re</b>

<h2>Environments Used </h2>

- <b>Google Colab</b> (21H2)
